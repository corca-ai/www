# Internationalization

The site ships four locales: Korean at the root (`/`), English under `/en/`,
Japanese under `/ja/` and Simplified Chinese under `/zh/`. It uses Astro's
built-in i18n routing with no prefix on the default Korean locale, matching the
original site's URLs. The integrated `/blog` section is the static-asset
exception: public article content is shared, while `/en/blog`, `/ja/blog` and
`/zh/blog` provide localized shells with the matching main-site navigation and
language switcher.

Indexable localized pages use language-wide `hreflang` values: `ko`, `en`, `ja`
and `zh-Hans`, plus `x-default` pointing to the Korean URL. Each translation
cluster lists only the locale URLs that actually exist and are indexable.
`noindex` pages do not emit or receive hreflang references. Document language,
Open Graph locale and date-format locale values remain separate contracts and
may retain region-specific tags such as `zh-CN`, `zh_CN` and `ko-KR`.

## Where content lives

- `src/i18n/ui.ts` — the locale list plus navigation, footer and home strings.
- `src/i18n/pageMeta.ts` — per-page SEO titles and descriptions for the static
  pages; product pages carry their own per-locale copy in their manifest ([products](products.md)).
- `src/i18n/structuredData.ts` — localized schema.org nodes (breadcrumbs and the
  product `SoftwareApplication`) merged into each page's JSON-LD.
- `src/components/pages/ax/content.ts` — the complete AX page, carousel and form
  copy for all locales; see the [AX guide](ax.md).
- `src/content/` — news and colleague entries as YAML, one file each, translated
  per locale and validated by a schema.
- `src/i18n/utils.ts` — helpers such as `localizePath` and locale detection.

Each page is authored once as a component and rendered per locale by a single
dynamic route, as described in [architecture](architecture.md). Adding an article, colleague or
locale is walked through in the [runbook](runbook.md). Translation edits flow into the
build like any other change, so run the checks in [development](development.md) afterwards.

## Localized line wrapping

Shared typography keeps Korean headings and paragraphs on space-delimited
boundaries with `word-break: keep-all`. Do not extend that rule to Japanese or
Simplified Chinese: those locales use native CJK wrapping with strict punctuation
handling so long, space-less sentences cannot widen a grid beyond the viewport.
Japanese and Chinese body copy uses normal greedy wrapping; reserve
`text-wrap: pretty`, authored line breaks or non-wrapping phrases for headings
whose composition has been reviewed at the supported breakpoints. Content-grid
children must remain shrinkable with `min-width: 0`, and hiding horizontal
overflow is not an acceptable substitute for fixing the overflowing text or
layout item.

## Localization checklist

| Content type | Source | Locale requirement |
| --- | --- | --- |
| Navigation, footer and shared UI strings | `src/i18n/ui.ts` | Every locale key is required by TypeScript usage. |
| Static page SEO metadata | `src/i18n/pageMeta.ts` | Every static page needs title and description for every locale. |
| Static page body copy | `src/components/pages/*.astro` | Components receive `lang`; keep visible copy complete for every locale they render. |
| Product category cards and SEO | `src/products/*/manifest.ts` | Product manifests carry per-locale `meta` and `blurb` values. |
| Product page body copy | `src/products/*/Page.astro` | Product pages receive `lang`; update bespoke page copy for every supported locale. |
| Corca AX body and form copy | `src/components/pages/ax/content.ts` | Keep the typed content shape complete for all four locales and preserve stable form topic IDs. |
| Structured data labels | `src/i18n/structuredData.ts` | Breadcrumb and schema.org text must match the rendered locale. |
| News and colleagues | `src/content/**/*.yaml` | Content schemas require translated keys for the supported locales. |
| Blog posts and shells | `public/blog/` and `public/{en,ja,zh}/blog/` | Keep shared post content, localized shells and language switcher links in sync. |

When adding a locale, update each source above, then verify the default Korean
paths plus the prefixed locale paths such as `/en/`, `/ja/` and `/zh/`.
