Korka 如何成为 OpenAI 精选合作伙伴？

作为 6 月份新入职的 AX 顾问，这个故事包含了对 Corca 被选为 OpenAI Select Partner 获得新认识的过程。

2026年7月28日 문정민(AX Consultant), 배휘동(AX Lead)

去年二月签署OpenAI服务合作伙伴合同随着 7 月 14 日 OpenAI 合作伙伴网络的推出，Han Korka 被选为 OpenAI 精选合作伙伴！现在Corca 在 OpenAI 合作伙伴网络上的官方简介您还可以在这里查看 Corca。

6月份加入Korca担任AX顾问后，我经常从周围的人那里听到这个问题。

“尽管是一家早期初创公司，Corca 与 OpenAI 合作的原因是什么？

说实话，一开始我也不知道答案。因为我知道 Corca 是一个为公司提供 AX 帮助的团队，所以我认为他们在为客户提供 AX 咨询方面的经验是主要因素。但在询问同事、审视行业、深入挖掘 Corca 的历程后，我发现还有更深层次的故事。韩国类似的公司太多了，不能仅仅因为我们是“AX 咨询初创公司”就被选为合作伙伴。

我发现的两个关键因素是多年开发AI产品积累的运营知识, 和Korka 转型 AI 原生团队积累的 AX 专业知识是的。AX 团队负责人 Bae Hwi-dong我详细询问并总结了我所了解到的情况。

多年来开发AI产品时积累的运营知识

我首先检查的是 Corca 是一个在成为帮助 AX 的公司之前自己创建和运营产品的团队。

早在 2022 年底 ChatGPT 发布之前，Korca 就已经感受到了 LLM 的潜力，并通过使用 AI 开发广告优化和推荐系统，产生了可观的销售额。经过各种尝试，从2024年开始，Corca目前的旗舰产品以“AI加速科学研究”为愿景，月光被释放了。

Moonlight 是一款人工智能研究伴侣，可帮助研究人员更快、更深入地阅读和理解论文。我们将通过翻译和总结快速理解论文、讨论阅读原文时遇到的概念、以及在代理的帮助下轻松解决复杂图纸的经验融入到我们的产品中。即使在 Corca 内部，也有人担心领域可能太窄，但我们能够集中精力，并且真实用户声音据说，由于产品的改进，许多国家的大学和研究人员每天都在使用Moonlight。最近不只是看论文，还有KCCV之类的东西。轻松浏览会议论文还添加了一个功能。

然而，即使听到这个故事，一开始我也没有立即明白 Moonlight 与选择 OpenAI 合作伙伴有什么关系。不过听了辉东的解释，我终于明白为什么“AI产品运营经验”对于AX组织来说至关重要。

“AX 不仅仅是取代您自己工作的代理。当然，在许多任务中，使用 Codex Skill 和 Computer Use 在每台计算机上运行代理就足够了。然而，为了使代理商在组织的标准化流程中发挥作用，他们需要掌握如何在保持质量水平的同时控制 API 成本的专业知识。创建一个代理和真正渗透每个成员的习惯并引起行为改变是完全不同的问题，但将人工智能产品融入用户日常生活的经验也非常有帮助。”

这自然是第二个关键因素。Corca 内部积累的 AX 专业知识事情还在继续。

Korka 转型 AI 原生团队积累的 AX 专业知识

Hwidong表示，在与OpenAI的沟通过程中，Corca的两大核心优势，以及Corca的AI产品运营能力，被评价为非常令人印象深刻。

  • 对法典的深入实践熟练程度

    OpenAI希望有一个团队能够在客户引入Codex时遇到困难时能够立即提供解决方案，并赞扬Corca团队深入使用Codex并充分理解其机制。

  • 基于实践经验的组织变革管理能力

    对于市场上极为稀缺的OCM能力，他表示，对Corca去年以来一直追求的自下而上的AX冠军培育和自上而下的AX环境构建并行策略的深度感，以及Corca通过从内部构建AI原生组织而建立的实际信心。

当我加入 Corca 时，已经斧头日Corca 内部的 AX 文化（称为 AX 共享协会）已经很成熟。结对工作经常发生，每周都会出现新的想法和产品原型，并且当每个人分享自己的工具和专业知识时，学习就会发生。

然而，当我意识到这些事情从一开始就不太顺利，从去年开始经过各种实验、试错才变成了现在的样子时，我又看到了它们。我认为这种小小的组织变革的经历很快就会让人们对咨询产生信心。 Hwidong 补充道，“AX 中没有正确答案。”

“Korka 对 AX 是真诚的，但这绝对不意味着 Corka 提出的就是正确的答案，你必须遵循它。事实上，AX 中没有正确的答案。这是一个非常混乱的时代，社交媒体说昨天被认为‘疯狂’的最佳实践今天‘死了’。因此，组织成员创造和发展适合个人和组织情况的技能的过程，而不是别人工作的结果，必须转移为“经验”而不是“正确答案”。”

选择我终于正确理解的合作伙伴选择新闻

在撰写本文时，我了解到 Korka 不断将其从运营 AI 产品中学到的知识以及自身的变革经验连接到客户的 AX 中。

因此，现在 Korka 被选为 OpenAI 精选合作伙伴的消息看起来不仅仅是添加到您的个人资料中的徽章。从产品到让企业团队能够在工作中继续使用人工智能，在我加入公司的短时间内，我看到Corca是一个一直在共同思考这两个领域的团队。
